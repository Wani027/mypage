เหตุผลที่อยากเรียน Full stack web development

  • อยากเรียนรู้และเข้าใจวิธีการสร้างเว็ป
  • อยากเรียนรู้แนวคิดและวิธีออกแบบ UX/UI

ความคาดหวังต่อวิชานี้

  • พัฒนาเว็ปที่ใช้งานได้จริง
  • ได้เข้าสังคมใหม่ๆจากงานกลุ่ม
  • ได้เกรดมากกว่า F

อะไรจุดอ่อน ที่ตนเองต้องพัฒนาเกี่ยวกับทักษะ Programming และ แนวทางการพัฒนา

จุดอ่อน

  • ความจำ code ว่าแต่ละคำสั่งมีความหมายอย่างไรใช้อย่างไร
  • ภาษา เนื่องจากภาษาที่ส่วนมากเป็นภาษาอังกฤษ

แนวทางการพัฒนา

  • ฝึกฝนและใช้บ่อยๆ
  • ใช้เครื่องมือช่วยแปลภาษาและฝึกจำความหมายและวิธีใช้
